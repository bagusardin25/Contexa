# Notewave

Realtime collaborative notes for students: shared lecture notes, group projects, and study
guides that the whole group can edit at the same time.

## Features

- Live co-editing with presence, so you see who is in a note.
- Markdown notes with code blocks, tables, and images.
- Semantic search across all notes in a workspace.
- Works offline and syncs when you're back online.

## Team

Notewave is built by a team of three students: one on the editor and realtime sync, one on
the backend and database, and one on design and user research.

## Roadmap

Q4 2026: student pilot with three partner campuses. Pricing and team plans will be
evaluated after the pilot, based on how groups actually use shared workspaces.

2027: mobile apps for iOS and Android, and an integration with campus learning platforms.

## Getting started

Sign in with a campus Google account, create a workspace for your group, and invite your
classmates with a link.
